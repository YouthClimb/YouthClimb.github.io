# 原站盘点与迁移对应

## 当前内容归属

按网站所有者确认：《生说》和《御光师》是原创小说，寄放在网站上，与朋友们的真实共同经历独立。现设 `/novels/` 小说板块和两个作品子板块 `/novels/shengshuo/`、`/novels/yuguangshi/`。5 篇小说章节以 `section: novels` 标识，按原章节编号排列，同一作品内提供前后章导航。`Hello World` 为 `section: legacy` 的旧站示例。其他文档尚未上传，共同经历首页和年月归档呈现空状态。

下文的原站盘点描述旧站情况；“旧地址保留”表示链接继续可访问，不代表继续把小说计入共同经历。原小说分类路径现在呈现小说目录，旧分页及年月路径保留并按共同经历规则显示。全站标签、搜索与订阅保留所有已发布内容，搜索和阅读页注明内容归属。

原站没有照片相册、活动报名、登录、评论、在线内容管理或后端数据库。本次没有虚构朋友的姓名、活动、照片和经历，也没有引入后端依赖。新增真实经历与小说共用内容文件管理机制，通过明确的 `section` 字段隔离板块；分类与标签仅作为各板块中的内容索引。

## 保留证明

`archive/migration.json` 记录原始 34 个文件的 SHA-256、ZIP 快照哈希、6 篇正文哈希、12 个资源副本及 21 个页面地址。迁移工具在保存原始 ZIP 和资源、校验原文件未发生变化后，才移除旧目录中逐个明确列出的原文件，未递归删除项目目录。

`npm run verify` 会检查迁移正文哈希、构建后正文、原始资源副本、ZIP、全部旧页面路径和全站内部链接 / 锚点。历史 HTML 仍可从原站 ZIP 解压查看。

## 维护边界

内容、资源和表现分离：普通增添内容只操作 Markdown 与媒体目录；新增小说作品只需增加一份 `src/content/novels/*.json` 元数据。只有新增网站能力或改变布局时才需修改 Astro 组件。分类、标签、文章数量及归档不写死在页面中。当前为静态文件托管，发布内容仍需一次构建；不提供无需构建的在线多人编辑。
